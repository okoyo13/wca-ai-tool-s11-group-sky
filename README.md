## WHAT IS IYF EXPOUNDER.


This tool helps a student to know more about Chapel classes,the course he/she wants to take,when and where.The things that work in handy to ensure smooth learning and also academic code of conduct.Importance of the school passport,when and where to use it.

## How to Run

1. Install the required packages
2. Create an.env file.
3. Add your Gemini API key
4. Run main.py

## How to set an API key

1. Go to the Google AI Studio Platform
2. Create account.
3. Navigate to the API keys page
4. Click Create new secret key.
5. Give the key  name (optional), then click Create.
6. Copy the key and paste it the dotenv file.
